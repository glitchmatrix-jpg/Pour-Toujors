# Pour Toujours — APK QA guide

The Android APK is generated by `.github/workflows/android-apk.yml`.

## Generate a build

1. Open the repository on GitHub.
2. Open **Actions**.
3. Select **Android APK**.
4. Choose **Run workflow**.
5. Select the `agent/initial-product-foundation` branch.
6. Choose `both` for the build mode.
7. Wait for **Validate and build APK** to finish successfully.

The workflow blocks APK delivery when Flutter analysis, tests, asset verification, or Android compilation fails.

## Download

Open the completed workflow run and download one of these artifacts:

- `pour-toujours-debug-<run>` — best for first functional QA and readable crash diagnostics.
- `pour-toujours-release-qa-<run>` — best for realistic performance and animation testing.

Each artifact includes `SHA256SUMS.txt` for integrity checking.

## Install on Android

1. Download and unzip the artifact.
2. Transfer the APK to the phone if it was downloaded elsewhere.
3. Open the APK.
4. Allow installation from the browser or file manager when Android prompts.
5. Install the application.

This is a private QA build. It is not Play Store signed and must not be distributed as a production release.

## Required test pass

Test each item on the physical phone:

- fresh install opens identity selection;
- identity selection persists after force-closing and reopening;
- all fourteen profiles can be selected;
- Today scrolls without overflow, clipping, or blank sections;
- each city shows the correct local time;
- weather loads on Wi-Fi and mobile data;
- airplane mode shows a graceful weather failure state;
- pull-to-refresh retries weather;
- People, Calendar, and Settings open correctly;
- Settings changes identity only after an explicit tap;
- system back gesture behaves normally;
- text remains readable at large Android font sizes;
- content is not hidden by display cutouts or gesture navigation;
- dark system mode does not produce illegible system bars;
- app resumes correctly after being backgrounded;
- no visible frame drops during scrolling;
- no crashes after rotating the device;
- no misleading claim of live activity or location.

## Evidence to capture

Record:

- phone model;
- Android version;
- APK type and workflow run number;
- onboarding screenshot;
- complete Today screen screenshots;
- People, Calendar, and Settings screenshots;
- weather success and offline states;
- any overflow stripes, blank screens, delayed taps, crashes, or incorrect times.
