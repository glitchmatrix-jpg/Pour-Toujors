# Flutter migration

The Expo prototype branch is retained only as an early product sketch. Active development moves to Flutter/Dart on `agent/flutter-foundation`.

Why Flutter:
- consistent, custom-rendered mobile UI
- strong animation and visual composition primitives
- clean path to a premium, mobile-first experience
- native extensions can be added later for Android and iOS home-screen widgets

The app remains privacy-first: no live GPS, no background location, and no inferred activity beyond transparent routine-based estimates.
