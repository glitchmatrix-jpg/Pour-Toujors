# Asset direction

Pour Toujours uses an original illustration system rather than generic stock photography in its first milestone.

## Core motifs
- four-pane family window
- horizon lines
- sunrise, daylight, sunset, and moon phases
- restrained city silhouettes
- warm paper-like surfaces and deep navy night tones

## Launch assets
- app mark and wordmark
- four city-window SVG illustrations: Karachi, Chiba, Dublin, Hattiesburg
- avatar fallbacks based on initials
- weather glyphs using platform icons initially

All visual assets added to the repository must be original or have documented redistribution rights and attribution requirements.
