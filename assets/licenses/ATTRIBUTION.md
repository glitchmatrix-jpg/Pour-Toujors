## Distribution checklist

Before releasing the app:

1. Keep this file in the source repository.
2. Add an in-app **Licenses and acknowledgements** screen.
3. Include the Hattiesburg credit exactly as written above.
4. Preserve the Meteocons MIT license notice in the release documentation.
5. Do not replace these images with unverified search-result downloads.
